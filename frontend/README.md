# Real-Time Multiplayer Survival Game

A real-time multiplayer survival game built using React, Node.js, and Socket.IO.

## Features

- Real-time multiplayer gameplay
- Room creation and joining
- Player ready/start system
- Real-time player movement
- Collision detection
- Red and blue player roles
- Player interaction and elimination mechanics
- Server-side game state management
- Simulated-client load testing

## Tech Stack

### Frontend
- React
- Vite
- Socket.IO Client

### Backend
- Node.js
- Express
- Socket.IO

## Architecture

```text
React Frontend
      ↓

Movement / Collision / Game Logic
